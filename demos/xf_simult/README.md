# 讯飞同声传译本地 Demo

只做一件事：浏览器采集普通话麦克风，经过本地代理实时送到讯飞同声传译，显示中文原文和英文译文，并连续播放讯飞返回的英文 TTS 译音。

项目根目录的 `.env` 需包含：

```dotenv
XF_APPID=...
XF_API_KEY=...
XF_API_SECRET=...
```

从项目根目录启动：

```bash
uv run python demos/xf_simult/server.py
```

然后打开 <http://127.0.0.1:8766>。服务只监听本机地址；凭据不会发送到浏览器，录音不会落盘。译音默认开启，使用时建议佩戴耳机，避免扬声器声音再次进入麦克风。
